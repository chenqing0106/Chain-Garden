# 🚀 Chain Garden 快速开始指南

欢迎使用 Chain Garden！本指南将帮助你在 5 分钟内启动并运行项目。

## 📋 前置要求

- Node.js >= 18
- MetaMask 浏览器扩展
- Sepolia 测试网 ETH（用于 Gas 费，可选）

## 🔧 第一步：安装依赖

```bash
# 在项目根目录
npm install

# 安装前端依赖
cd frontend
npm install
```

## 🔑 第二步：配置环境变量

在项目**根目录**创建 `.env` 文件：

```env
# AI 服务（二选一或都配置）
QWEN_API_KEY=your_qwen_api_key_here      # 推荐：阿里云通义千问
GEMINI_API_KEY=your_gemini_api_key_here  # 可选：Google Gemini

# 明确指定使用的 AI 服务（可选）
AI_SERVICE_PROVIDER=qwen  # 或 gemini

# Pinata IPFS（NFT 铸造需要）
VITE_PINATA_JWT=your_Pinata_JWT_Token

# Sepolia RPC（合约部署需要）
SEPOLIA_RPC_URL=https://sepolia.infura.io/v3/YOUR_INFURA_KEY
PRIVATE_KEY=your_private_key_here
```

### 获取 API Key

**Qwen API Key（推荐）：**
1. 访问：https://dashscope.console.aliyun.com/
2. 注册/登录阿里云账号
3. 开通 DashScope 服务
4. 在 API-KEY 管理页面创建新的 API Key

**Gemini API Key（可选）：**
1. 访问：https://aistudio.google.com/app/apikey
2. 登录并创建 API Key

**Pinata JWT：**
1. 访问：https://www.pinata.cloud/
2. 登录后进入 Dashboard
3. 点击右上角头像 → "API Keys"
4. 点击 "New Key"，填写名称，勾选 "Admin"
5. 复制 JWT Token（只显示一次，请保存）

## 🚀 第三步：启动应用

### 方式一：从根目录启动（推荐）

```bash
# 在项目根目录
npm run dev
```

### 方式二：从 frontend 目录启动

```bash
cd frontend
npm run dev
```

访问：http://localhost:5173（或终端显示的端口）

## ✅ 第四步：验证安装

1. **测试 AI 功能**：
   - 在输入框中输入一个 vibe（如："Techno spikes"）
   - 点击 "GENERATE FROM VIBE"
   - 应该能成功生成植物 DNA

2. **测试音频功能**：
   - 点击 "START AUDIO INPUT"
   - 允许浏览器访问麦克风
   - 应该能看到音频可视化

3. **测试钱包连接**：
   - 点击 "CONNECT WALLET"
   - 在 MetaMask 中批准连接
   - 应该能看到钱包地址

## ⚠️ 常见问题

### API Key 无效？

- ✅ 确认 `.env` 文件在**根目录**（不是 `frontend` 目录）
- ✅ 确认 API Key 格式正确
- ✅ **重启开发服务器**（修改 `.env` 后必须重启）

### 找不到环境变量？

- ✅ 检查 `vite.config.ts` 中的路径配置
- ✅ 确认 `.env` 文件名称正确（不是 `.env.local` 或其他）
- ✅ 确认 `.env` 文件在根目录

### 端口冲突？

- ✅ 修改 `frontend/vite.config.ts` 中的端口配置
- ✅ 或使用 `npm run dev -- --port 3001` 指定端口

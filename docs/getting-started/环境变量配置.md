# 环境变量配置指南

本文档详细说明 Chain Garden 项目所需的所有环境变量。

## 📁 文件位置

在项目**根目录**创建 `.env` 文件（与 `package.json` 同级）。

## 🔑 必需的环境变量

### AI 服务配置（至少配置一个）

#### Qwen API Key（推荐）

```env
QWEN_API_KEY=your_qwen_api_key_here
```

**获取方式：**
1. 访问：https://dashscope.console.aliyun.com/
2. 注册/登录阿里云账号
3. 开通 DashScope 服务
4. 在 API-KEY 管理页面创建新的 API Key

#### Gemini API Key（可选）

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

**获取方式：**
1. 访问：https://aistudio.google.com/app/apikey
2. 登录并创建 API Key

#### 指定 AI 服务提供商（可选）

```env
AI_SERVICE_PROVIDER=qwen  # 或 gemini
```

如果不指定，系统会按以下优先级自动选择：
1. 如果设置了 `QWEN_API_KEY`，默认使用 Qwen
2. 如果只设置了 `GEMINI_API_KEY`，使用 Gemini
3. 如果两者都设置了，默认使用 Qwen

### IPFS 配置（NFT 铸造需要）

```env
VITE_PINATA_JWT=your_Pinata_JWT_Token
```

**获取方式：**
1. 访问：https://www.pinata.cloud/
2. 登录后进入 Dashboard
3. 点击右上角头像 → "API Keys"
4. 点击 "New Key"，填写名称，勾选 "Admin"
5. 复制 JWT Token（只显示一次，请保存）

**可选配置：**
```env
VITE_PINATA_API_BASE=https://api.pinata.cloud
VITE_PINATA_GATEWAY=https://gateway.pinata.cloud/ipfs
```

## 🔧 可选的环境变量

### 区块链配置（合约部署需要）

```env
# Sepolia RPC URL
SEPOLIA_RPC_URL=https://sepolia.infura.io/v3/YOUR_INFURA_KEY

# 部署者私钥（不要提交到Git！）
PRIVATE_KEY=your_private_key_here

# Etherscan API Key (可选，用于合约验证)
ETHERSCAN_API_KEY=your_etherscan_key
```

**获取 Sepolia RPC URL：**
1. 访问 [Infura](https://infura.io) 或 [Alchemy](https://www.alchemy.com)
2. 注册账户并创建新项目
3. 选择 Sepolia 测试网络
4. 复制 RPC URL

**获取 Etherscan API Key：**
1. 访问 [Etherscan](https://etherscan.io/apis)
2. 注册并创建 API Key


## 🔒 安全提示

⚠️ **重要：**

- ✅ 永远不要将 `.env` 文件提交到 Git
- ✅ 确保 `.env` 在 `.gitignore` 中（已默认忽略）
- ✅ 不要在生产环境中使用主账户的私钥
- ✅ 定期轮换 API 密钥
- ✅ 使用环境变量管理工具（如 AWS Secrets Manager）存储生产密钥

## 🔍 验证配置

### 检查环境变量是否加载

在浏览器控制台运行：

```javascript
// 检查 AI 服务配置
console.log('QWEN_API_KEY:', import.meta.env.QWEN_API_KEY ? '已配置' : '未配置');
console.log('GEMINI_API_KEY:', import.meta.env.GEMINI_API_KEY ? '已配置' : '未配置');

// 检查 IPFS 配置
console.log('VITE_PINATA_JWT:', import.meta.env.VITE_PINATA_JWT ? '已配置' : '未配置');
```

### 测试 API Key

1. **测试 Qwen API**：
   - 在应用中输入一个 vibe（如："Techno spikes"）
   - 点击 "GENERATE FROM VIBE"
   - 检查是否成功生成植物 DNA

2. **测试 IPFS**：
   - 创建一个植物并尝试铸造 NFT
   - 检查是否能成功上传到 IPFS

## 🐛 常见问题

### 问题 1：环境变量未生效

**原因：**
- 修改 `.env` 后没有重启开发服务器
- `.env` 文件位置不正确

**解决：**
1. 停止开发服务器（Ctrl+C）
2. 确认 `.env` 文件在根目录
3. 重新启动：`npm run dev`

### 问题 2：Vite 无法读取环境变量

**原因：**
- Vite 只读取以 `VITE_` 开头的环境变量（除了特殊配置）

**解决：**
- 对于前端使用的变量，确保以 `VITE_` 开头
- 或在 `vite.config.ts` 中使用 `define` 手动注入

### 问题 3：API Key 格式错误

**检查：**
- Qwen API Key：通常以 `sk-` 开头
- Gemini API Key：通常以 `AIzaSy` 开头
- Pinata JWT：是一个 JWT token 字符串

```solidity
// PlantPartNFT.sol
contract PlantPartNFT is ERC721 {
    enum PartType { Root, Stem, Branch, Leaf }
    
    struct PartInfo {
        uint256 seedId;
        PartType partType;
        string chainName;
    }
    
    mapping(uint256 => PartInfo) public partInfo;
    mapping(uint256 => mapping(PartType => uint256)) public seedParts;
    
    function mintPart(
        uint256 seedId,
        PartType partType,
        string memory metadataURI
    ) public payable returns (uint256 tokenId) {
        require(seedParts[seedId][partType] == 0, "Part already minted");
        
        tokenId = _nextTokenId++;
        _safeMint(msg.sender, tokenId);
        _setTokenURI(tokenId, metadataURI);
        
        partInfo[tokenId] = PartInfo({
            seedId: seedId,
            partType: partType,
            chainName: getChainName()
        });
        
        seedParts[seedId][partType] = tokenId;
    }
}
```

## 数据流设计

### 种子 DNA 传递

```
ZetaChain (种子)
    ↓ (seedId + DNA)
Bitcoin (根) ← 使用 seedId 验证 DNA
    ↓
Ethereum (茎) ← 使用 seedId 验证 DNA
    ↓
Polygon (枝干) ← 使用 seedId 验证 DNA
    ↓
Arbitrum (叶子) ← 使用 seedId 验证 DNA
    ↓
ZetaChain (组装) ← 所有部分 + DNA 验证
```

### 元数据结构

每个部分的元数据必须包含：

```json
{
  "seedId": "0x1234...",
  "partType": "root|stem|branch|leaf",
  "dnaHash": "0xabcd...",  // DNA 的哈希，用于验证一致性
  "chain": "Bitcoin|Ethereum|Polygon|Arbitrum",
  "image": "ipfs://...",
  "attributes": [...]
}
```

### 1. DNA 一致性验证

```typescript
// 在铸造部分时验证 DNA
async function verifyDNA(seedId: string, dna: PlantDNA) {
  // 1. 从 ZetaChain 获取原始 DNA
  const originalDNA = await seedContract.getSeedDNA(seedId);
  
  // 2. 计算 DNA 哈希
  const dnaHash = keccak256(JSON.stringify(dna));
  const originalHash = keccak256(JSON.stringify(originalDNA));
  
  // 3. 验证一致性
  if (dnaHash !== originalHash) {
    throw new Error("DNA mismatch");
  }
}
```

```typescript
async function switchToChain(chainId: number) {
  try {
    await window.ethereum.request({
      method: "wallet_switchEthereumChain",
      params: [{ chainId: `0x${chainId.toString(16)}` }]
    });
  } catch (error) {
    // 如果链不存在，添加链
    await addChain(getChainConfig(chainId));
  }
}
```

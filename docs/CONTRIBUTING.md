# 🤝 贡献指南

感谢你对 Chain Garden 项目的关注！本文档将帮助你了解如何参与项目贡献。

## 📚 文档访问权限

### 公开文档

所有用户都可以访问 `docs/` 目录下的公开文档：
- `getting-started/` - 快速开始指南
- `guides/` - 详细技术指南
- `troubleshooting/` - 故障排除文档

### 私有文档

贡献者和维护者可以访问 `docs/private/` 目录下的内部文档：
- 内部开发流程
- 敏感配置信息
- 团队内部约定

**如何成为贡献者？**
1. Fork 本项目
2. 创建你的特性分支
3. 提交你的更改
4. 发起 Pull Request
5. 通过审查后，你将获得访问私有文档的权限

## 🚀 开始贡献

### 1. 设置开发环境

查看 [快速开始指南](./getting-started/快速开始.md) 了解如何设置开发环境。

### 2. 选择任务

- 查看 [Issue 列表](https://github.com/your-repo/chain-garden/issues)
- 选择你感兴趣的任务
- 在 Issue 中留言表示你要处理该任务

### 3. 开发流程

1. Fork 仓库
2. 创建特性分支：`git checkout -b feature/your-feature-name`
3. 提交更改：`git commit -m 'Add some feature'`
4. 推送分支：`git push origin feature/your-feature-name`
5. 提交 Pull Request

## 📝 代码规范

- 遵循项目的代码风格
- 添加必要的注释
- 编写清晰的提交信息
- 确保代码通过测试

## 🔍 代码审查

所有 Pull Request 都需要经过代码审查：
- 至少需要一名维护者批准
- 确保所有测试通过
- 确保文档已更新

## 📞 获取帮助

- 提交 Issue 提问
- 联系项目维护者

---

感谢你的贡献！🎉

## 0. 核心映射逻辑：文字→DNA，音频→生长

### 0.1 通俗理解：就像种植物一样

想象一下，你正在种一棵虚拟植物：

1. **第一步：AI 帮你设计"种子"（DNA）**
   - 你输入一段文字，比如："一个悲伤的夜晚，月光如水"
   - AI 就像一位植物设计师，分析你的文字，决定这棵植物应该长什么样
   - AI 会思考：
     - 情绪是什么？→ 悲伤 → 选择 `melancholic`（忧郁）情绪
     - 能量如何？→ 平静 → 能量值设为 0.3
     - 应该是什么形状？→ 下垂的感觉 → 选择 `weeping_willow`（垂柳）架构
     - 颜色应该是什么？→ 冷色调 → 生成蓝色、灰色调色板

2. **第二步：音频让植物"活起来"（生长）**
   - DNA 决定了植物的"基因"，但植物不会自己长出来
   - 需要音频作为"养分"，驱动植物实时生长
   - 就像给植物浇水、施肥一样，音频的不同频率控制植物不同部位的生长

### 0.2 AI 解析文字 → 生成 DNA 的详细过程

#### 代码实现位置
- **AI 服务**：`frontend/services/ai/qwenService.ts`

#### 工作流程

```typescript
// 1. 用户输入文字
const userInput = "一个悲伤的夜晚";

// 2. AI 服务分析文字（qwenService.ts）
async generatePlantDNA(vibe: string): Promise<PlantDNA> {
  // 构建分析 prompt
  const prompt = buildTextAnalysisPrompt(vibe);
  
  // 调用 AI API，让 AI 分析文字的情绪、能量、视觉特征
  const response = await fetch('...', {
    body: JSON.stringify({
      messages: [{ role: 'user', content: prompt }]
    })
  });
  
  // 3. AI 返回 JSON 格式的 PlantDNA
  const plantDNA = JSON.parse(response.content);
  return plantDNA;
}
```

#### AI 如何分析文字？

AI 会根据以下维度分析你的文字（见 `prompts.ts`）：

```typescript
// AI 分析任务清单
1. 确定情绪基调（Mood）
   - happy（快乐）
   - melancholic（忧郁）
   - mysterious（神秘）
   - aggressive（激进）
   - calm（平静）

2. 确定能量等级（Energy）
   - 0.0 = 静止/死寂
   - 1.0 = 混乱/爆发

3. 选择合适的生长架构（Architecture）
   - fractal_tree: 稳定、成长、历史感
   - organic_vine: 游走、灵活、流动
   - weeping_willow: 悲伤、沉重、下垂
   - ... 共 8 种架构
```

### 0.3 音频驱动植物生长的详细过程

#### 代码实现位置
- **植物画布**：`frontend/components/PlantCanvas.tsx`
- **音频分析**：`frontend/services/plantMusicService.ts`

#### 核心机制：频段分区生长

音频被分成三个频段，每个频段控制植物不同部位：

```
┌─────────────────────────────────────────┐
│        频段分区生长机制                  │
├─────────────────────────────────────────┤
│                                         │
│  🎵 低频 (Bass)    → 根部/主干           │
│  🎵 中频 (Mid)     → 中间分支            │
│  🎵 高频 (Treble)  → 末端/叶子           │
│                                         │
└─────────────────────────────────────────┘
```

#### 代码实现（PlantCanvas.tsx）

```typescript
// 1. 定义三个频段的生长进度
const bassGrowthRef = useRef<number>(0);    // 低频 → 根部/主干
const midGrowthRef = useRef<number>(0);     // 中频 → 中间分支
const trebleGrowthRef = useRef<number>(0);  // 高频 → 末端/叶子

// 2. 实时获取音频频谱数据
const audio = analyzer.getFrequencyData();
// 返回：{ bass: 120, mid: 80, treble: 150 }

// 3. 根据音频强度更新生长进度
const updatePhysics = (audio) => {
  const { bass, mid, treble } = audio;
  
  // 低频驱动根部生长
  if (bass > 20) {
    const bassGrowthRate = (bass / 255) * growthSpeed * 1.2;
    bassGrowthRef.current = Math.min(100, bassGrowthRef.current + bassGrowthRate);
  }
  
  // 中频驱动中间层生长
  if (mid > 20) {
    const midGrowthRate = (mid / 255) * growthSpeed * 1.0;
    midGrowthRef.current = Math.min(100, midGrowthRef.current + midGrowthRate);
  }
  
  // 高频驱动末端生长
  if (treble > 20) {
    const trebleGrowthRate = (treble / 255) * growthSpeed * 0.8;
    trebleGrowthRef.current = Math.min(100, trebleGrowthRef.current + trebleGrowthRate);
  }
};
```

#### 实时脉冲效果

当音频频率突然增强时，会触发视觉脉冲：

```typescript
// 检测频率变化量
const bassDelta = bass - lastBassRef.current;

// 如果变化量 > 30，触发脉冲
if (bassDelta > 30) {
  bassPulseRef.current = Math.min(1.0, bassDelta / 80);
  // 脉冲效果：线条变粗、节点变大、叶子扩展
} else {
  // 脉冲逐渐衰减
  bassPulseRef.current = Math.max(0, bassPulseRef.current - 0.08);
}
```

**视觉效果**：
- 低频突然增强 → 根部/主干"膨胀"一下
- 中频突然增强 → 中间分支"抖动"
- 高频突然增强 → 叶子"展开"

#### 绘制时应用生长进度

```typescript
// 在绘制分形树时，根据深度决定使用哪个频段的生长进度
const getDepthGrowth = (depth: number, maxDepth: number) => {
  const bassZone = maxDepth * 0.3;  // 前30%由低频控制
  const midZone = maxDepth * 0.6;   // 30%-60%由中频控制
  
  if (depth <= bassZone) {
    return bassGrowthRef.current;  // 根部用低频
  } else if (depth <= midZone) {
    return midGrowthRef.current;   // 中间用中频
  } else {
    return trebleGrowthRef.current; // 末端用高频
  }
};

// 只有当对应频段的生长进度足够时，才绘制这一层
const minGrowthForDepth = (depth / maxDepth) * 80;
if (zoneGrowth < minGrowthForDepth) return; // 还没长到，不绘制
```

## 1. 核心数据结构

### 1.1 PlantDNA（植物基因）

植物的所有特征由 `PlantDNA` 接口定义，这是连接视觉和音乐的核心数据结构：

```typescript
interface PlantDNA {
  speciesName: string;           // 物种名称
  description: string;           // 描述文本
  
  // 结构逻辑
  growthArchitecture: string;    // 生长架构类型
  branchingFactor: number;       // 分支因子 (2-5)
  angleVariance: number;         // 角度变化
  
  // 视觉
  colorPalette: string[];        // 调色板 [茎干, 主叶, 高光]
  leafShape: string;             // 叶片形状
  leafArrangement: string;       // 叶片排列
  growthSpeed: number;           // 生长速度
  
  // 情绪与音乐特征
  mood: 'happy' | 'melancholic' | 'mysterious' | 'aggressive' | 'calm';
  energy: number;                // 能量级别 (0.0-1.0)
}
```

### 1.2 生长架构类型

系统支持 **8种生长架构**，每种都有独特的视觉表现：

| 架构 | 中文描述 | 视觉特点 |
|------|---------|---------|
| `fractal_tree` | 分形树 | 稳定、成长、历史感 |
| `organic_vine` | 有机藤蔓 | 游走、灵活、流动 |
| `radial_succulent` | 放射多肉 | 聚焦、几何、曼陀罗 |
| `fern_frond` | 蕨类叶 | 数学、精确、重复 |
| `weeping_willow` | 垂柳 | 悲伤、沉重、下垂 |
| `alien_shrub` | 外星灌木 | 故障、怪异、意外 |
| `crystal_cactus` | 水晶仙人掌 | 尖锐、防御、棱角 |

## 2. 植物生长逻辑

### 2.1 频段分区生长系统

植物的不同部位由**不同音频频段**驱动生长：

```
┌─────────────────────────────────────────────────┐
│              频段分区生长机制                    │
├─────────────────────────────────────────────────┤
│                                                 │
│   🎵 低频 (Bass)    → 根部/主干 (depth 0-30%)   │
│   🎵 中频 (Mid)     → 中间分支 (depth 30-60%)   │
│   🎵 高频 (Treble)  → 末端/叶子 (depth 60-100%) │
│                                                 │
└─────────────────────────────────────────────────┘
```

**代码实现核心**：

```typescript
}
```

## 3. 音乐生成逻辑

### 3.1 情绪音阶系统

5种情绪对应不同的**音乐音阶**：

```typescript
const SCALES = {
  happy: ['C4', 'D4', 'E4', 'G4', 'A4', 'C5', 'D5'],     // 五声大调
  melancholic: ['A3', 'C4', 'D4', 'E4', 'G4', 'A4', 'C5'], // 五声小调
  mysterious: ['C4', 'C#4', 'E4', 'F#4', 'G4', 'B4', 'C5'], // Lydian #5 / 异域
  aggressive: ['C3', 'C#3', 'F3', 'F#3', 'G3', 'Bb3', 'C4'], // Locrian / 减音阶
  calm: ['C4', 'D4', 'E4', 'F#4', 'G4', 'A4', 'B4']       // Lydian (梦幻)
};
```

### 3.2 架构-合成器映射

每种植物架构使用不同的**合成器类型**：

| 架构 | 合成器 | 音色特点 |
|------|--------|---------|
| `fractal_tree` | FMSynth | 高谐波、复杂调制 |
| `organic_vine` | MonoSynth | 三角波、滤波包络 |
| `weeping_willow` | AMSynth | 幅度调制、下垂感 |
| `crystal_cactus` | FMSynth | 极高谐波、金属质感 |
| `alien_shrub` | DuoSynth | 双声道、颤音 |
| `data_blossom` | Synth | 纯正弦、滑音 |

### 3.3 生成式循环

使用 **Tone.Loop** 创建持续的音乐生成：

```typescript
const startGenerativeLoop = (dna: PlantDNA) => {
  const scale = SCALES[dna.mood];
  
  this.loop = new Tone.Loop((time) => {
    // Bass 触发（受 stress 影响）
    const bassThreshold = 0.15 + (this.bioState.stress * 0.2);
    if (Math.random() < cappedBassThreshold) {
      const bassNote = scale[0].replace('4', '2');
      this.bassSynth.triggerAttackRelease(bassNote, "8n", time);
    }

    // 主旋律（受 energy 影响）
    const density = 0.2 + (dna.energy * 0.15) + (this.bioState.energy * 0.2);
    if (Math.random() < cappedDensity) {
      const note = scale[Math.floor(Math.random() * scale.length)];
      const duration = this.bioState.stress > 0.7 ? "8n" : "4n";
      
      // 随机和弦生成
      if (Math.random() > 0.85) {
        const chord = [note, scale[(idx + 2) % scale.length], scale[(idx + 4) % scale.length]];
        this.synth.triggerAttackRelease(chord, duration, time);
      } else {
        this.synth.triggerAttackRelease(note, duration, time);
      }
    }
  }, "4n").start(0);
};
```

## 4. 双向反馈系统

植物和音乐形成**闭环反馈**：

```
┌─────────────────────────────────────────────────────────────────┐
│                      双向反馈系统                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌──────────┐                          ┌──────────────┐        │
│   │          │    PlantDNA (初始化)      │              │        │
│   │  AI 服务  │ ───────────────────────→ │  音乐服务     │        │
│   │          │                          │              │        │
│   └──────────┘                          └──────┬───────┘        │
│                                                │                │
│                                    BioState    │ 频谱数据       │
│                                    (stress,    ↓ (bass,        │
│                                     energy)    │  mid,          │
│                                         ↑      ↓  treble)       │
```

### 5.2 音频源类型

系统支持两种音频源：

| 音频源 | 类型 | 用途 |
|--------|------|------|
| `AudioAnalyzer` | 外部音频 | 麦克风/音频文件分析 |
| `PlantMusicService` | 生成音乐 | 基于 DNA 生成并分析自己的音乐 |

两种方式都实现 `AudioSource` 接口：

```typescript
interface AudioSource {
  getFrequencyData(): { 
    bass: number; 
    mid: number; 
    treble: number; 
    raw: Uint8Array 
  };
  cleanup?(): void;
}
```
